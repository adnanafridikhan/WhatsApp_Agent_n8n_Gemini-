# WhatsApp_Agent_n8n_Gemini-
WhatsApp AI Customer Support Agent 🤖💬 An automated WhatsApp conversational assistant built with n8n, Google Gemini, and conversation memory. Customers send a text message on WhatsApp, the workflow processes it with Gemini, and a reply is sent back automatically.
